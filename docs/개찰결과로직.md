# 개찰결과 로직

이 문서는 `개찰결과 도우미`의 `개찰결과 엑셀에 무효표, 실제낙찰사 표시` 기능이 현재 어떤 기준으로 동작하는지 정리한다.

기준 코드:

- `src/view/features/bid-helper/pages/BidResultPage.jsx`
- 참고 레거시 코드: `src/main/features/bid-result/applyOrderingResult.js`

## 처리 대상 파일

이 기능은 두 파일을 사용한다.

1. 개찰결과파일
   - 결과가 반영되는 대상 파일이다.
   - 첫 번째 시트를 기준으로 처리한다.
2. 발주처결과 파일
   - 무효표와 실제낙찰사 판정 기준으로 사용하는 파일이다.
   - 메인 시트는 항상 첫 번째 시트를 기준으로 처리한다.

현재 로직은 사용자가 선택한 발주처 값에 따라 별도 판정식을 바꾸지 않는다. 핵심 기준은 발주처결과 파일의 첫 번째 시트 구조다.

## 무효표 판정 기준

발주처결과 파일에서 유효 순번 목록을 만든다.

- 대상 시트: 첫 번째 시트
- 대상 열: A열
- 탐색 시작 행: 5행
- 최대 탐색 행: 5000행
- 순번이 나오기 시작한 뒤 빈 행이 3번 연속 나오면 탐색을 중단한다.
- A열 값에서 숫자만 추출해 순번으로 사용한다.

개찰결과파일에서는 다음 기준으로 무효 여부를 판단한다.

- 대상 시트: 첫 번째 시트
- 대상 행: 14행부터 마지막 데이터 행까지
- 대상 열: B열
- B열 순번이 발주처결과 파일의 A열 유효 순번 목록에 없으면 무효로 본다.

무효로 판단된 행은 다음처럼 반영한다.

- 개찰결과파일의 해당 행 B열 셀을 빨간색으로 표시한다.
- `B4` 셀에 `무효 N건`을 기록한다.

## 실제낙찰사 판정 기준

실제낙찰사는 발주처결과 파일의 첫 번째 시트에서 찾는다.

현재 웹 코드 기준은 다음과 같다.

1. 첫 번째 시트의 A열에서 노란색 셀을 찾는다.
2. 노란색 셀이 있는 같은 행을 실제낙찰사 후보 행으로 본다.
3. 그 같은 행에서 사업자번호를 찾는다.
4. 찾은 사업자번호를 개찰결과파일의 C열 사업자번호와 비교한다.
5. 일치하는 개찰결과파일 행의 O열에 `Y`를 쓴다.

노란색 판정은 현재 fill 색상 값이 `FFFF00`인지 확인하는 방식이다.

## 발주처결과 파일의 사업자번호 탐색 위치

실제낙찰사 후보 행이 정해지면, 그 행에서 사업자번호를 아래 순서로 찾는다.

```text
C열 -> D열 -> E열 -> B열 -> F열
```

각 셀의 값에서 숫자만 남겼을 때 10자리이면 사업자번호로 사용한다. 먼저 발견된 10자리 숫자를 사용한다.

예를 들어 발주처결과 파일에서 노란색 셀이 `A27`이면 사업자번호는 아래 순서로 확인한다.

```text
C27 -> D27 -> E27 -> B27 -> F27
```

정상 양식에서는 보통 C열, 즉 `C27`에서 사업자번호를 가져오는 구조다.

## 개찰결과파일 반영 위치

개찰결과파일에서는 다음 열을 사용한다.

- B열: 순번 비교 대상, 무효표 색상 반영 위치
- C열: 사업자번호 매칭 대상
- O열: 실제낙찰사 `Y` 표시 위치
- B4: 무효 건수 요약
- K4: 실제낙찰사 요약 문구

실제낙찰사 처리 시 O열은 14행부터 마지막 데이터 행까지 먼저 비운 뒤, 매칭된 행에만 `Y`를 다시 쓴다.

## 실제낙찰사 요약 문구

개찰결과파일의 `K3` 텍스트를 기준으로 `K4` 문구를 만든다.

- `K3`에 `예상낙찰사` 문구가 있으면 `실제낙찰사`로 바꾼다.
- 실제낙찰사 매칭 결과가 있으면 `K4`에 `균형근접`, 순위, 업체명 정보를 포함해 기록한다.

웹 코드에서는 여러 실제낙찰사가 잡히면 첫 번째 매칭 업체를 기준으로 표시하고, 나머지는 `외 N개사` 형태로 요약한다.

## 다음 변경 시 주의점

이 기능은 기존 GUI에서 검증된 판정 규칙을 웹으로 이관한 기능이다. 다음 세션에서 구조를 바꿀 경우, 아래 항목을 먼저 확정해야 한다.

- 실제낙찰사 표시 기준을 계속 A열 노란색으로 볼지
- 사업자번호 위치를 C열 고정으로 바꿀지, 현재처럼 여러 열 후보를 둘지
- 발주처결과 파일에 별도 표시 열을 둘지
- 개찰결과파일 O열 `Y` 표시 규칙을 유지할지
- 무효표 판정 기준인 발주처결과 A열 순번과 개찰결과 B열 순번 비교를 유지할지
