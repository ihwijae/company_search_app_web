# 순공사원가 가점 정리

## 적용 구간

| 공통 산식 | 적용 발주처 / 구간 |
| --- | --- |
| 입찰가격점수 70점, 차감계수 4, 기준점 65점 | LH 50억 미만(분담 포함), 행안부 30억 미만, 행안부 30억~50억 |
| 입찰가격점수 50점, 차감계수 2, 기준점 45점 | LH 50억~100억(분담 포함), 행안부 50억~100억 |

- 공통 계산: `src/shared/agreements/calculations/netCostBonus.js`
- 발주처와 구간별 차이는 설정으로 연결하고, 계산·반올림·절사 규칙은 함께 사용한다.
- 50억~100억 산식은 천 원 단위로 올린 예정가격 상한이 100억 이상이면 가점을 적용하지 않는다(기존 LH 규칙 유지).
- A값이 없거나 0이면 자동 가점은 0점이다(기존 LH 규칙 유지).
- 기존 저장 항목인 `netCostAmount`, `aValue`를 사용하므로 저장한 협정을 불러오면 자동 가점도 다시 계산된다.
- 행안부 세 구간은 협정 합계와 엑셀 템플릿의 `AG`열에도 계산한 가점을 반영한다.

## 공통 입력값
- Base: 기초금액
- NetCost: 순공사원가
- A: A값

## 예정가격(사정율 범위, 천원 미만 절상)
- 사정율 범위: 0.988 ~ 1.012
- 천원 단위 올림(엑셀 ROUNDUP, -3)
- ExpectedMin = ROUNDUP(Base * 0.988, -3)
- ExpectedMax = ROUNDUP(Base * 1.012, -3)

## 순공사원가 반영 입찰가격
- Bid = NetCost * (Expected / Base) * 0.98
- BidMin = NetCost * (ExpectedMin / Base) * 0.98
- BidMax = NetCost * (ExpectedMax / Base) * 0.98

## 비율 R (소수 4자리 반올림)
- R = (Bid - A) / (Expected - A)
- Rmin = ROUND((BidMin - A) / (ExpectedMin - A), 4)
- Rmax = ROUND((BidMax - A) / (ExpectedMax - A), 4)

## 입찰가격점수
- LH 50억 미만:
  - PriceScore(R) = 70 - 4 * ABS((0.9 - R) * 100)
- LH 50억~100억:
  - PriceScore(R) = 50 - 2 * ABS((0.9 - R) * 100)

## 가점 산출
- LH 50억 미만: 기준 65점 초과분만 가점
- LH 50억~100억: 기준 45점 초과분만 가점

- Bonus(R) = PriceScore(R) - 기준점
- FinalBonus = max(0, min(Bonus(Rmin), Bonus(Rmax)))
- 사정율 2개 경우 중 더 불리한(작은) 가점을 사용
- 최종 가점은 소수 2자리 **절사**

## 안내 문구 표시 조건
- Rmin 또는 Rmax가 0.9보다 크면
  - 헤더에 "올라탈수록 점수 깎임" 표시

## UI 표시 위치
- 헤더(기초금액 아래): 순공사원가 입력
- 헤더(투찰율 아래): 순공사원가가점 표시(0 또는 계산값)
- 테이블 하단: 입찰점수 옆 컬럼에 순공사원가가점 표시

## 행안부 투찰금액과 가능지분

- 적용 구간: 행안부 30억~50억, 50억~100억의 투찰금액 자동 모드
- 예정가격 = 기초금액 × 사정률
- 기존 투찰금액 = ROUND((예정가격 − A값) × 낙찰하한율 + A값, 0)
- 순공사원가 반영금액 = ROUNDUP(순공사원가 × 사정률 × 0.98, 0)
- 최종 투찰금액은 두 금액 중 큰 값이다. 순공사원가가 없으면 기존 산식을 사용한다.
- 순공사원가 반영금액은 무효 기준보다 낮아지지 않도록 원 단위 올림한다. 가점 표시값이나 수동 가점 보정값으로 반영 여부를 판단하지 않는다.
- 협정보드·후보·지역사 검색과 불러오기·엑셀 가능지분 모두 최종 투찰금액을 사용한다. 수동 모드는 입력한 투찰금액을 유지한다.
- 예: 기초금액 7,816,772,000원, 사정률 101.6%, 낙찰하한율 87.495%, A값 472,253,239원, 순공사원가 7,572,604,787원이면 기존 금액 7,007,768,484원보다 높은 **7,539,891,135원**을 사용한다.
- 공통 계산: `src/shared/agreements/calculations/bidAmount.js`
- LH, 행안부 30억 미만, 다른 발주처의 투찰금액 계산에는 이 비교 규칙을 적용하지 않는다.

## 확인

- `node scripts/check-net-cost-bonus.cjs`: 구간 연결, 가점 산출, 합계 반영, 엑셀 출력 데이터, 100억 경계, 입력 누락 검사
- `node scripts/check-bid-amount.cjs`: 사용자 예시, 두 투찰금액 비교, 원 단위 올림, 가능지분·지역사 검색 기준, 미적용 구간 검사
- 실제 웹 화면에서 행안부 세 구간의 입력·저장·불러오기와 엑셀 다운로드 결과를 추가 확인한다.
