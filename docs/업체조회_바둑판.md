# 업체조회 바둑판

## 목적

기존 업체조회 기능은 그대로 유지하고, 업체 정보를 엑셀처럼 한눈에 비교하기 위한 별도 화면이다.

기존 업체조회가 `검색조건 | 검색 결과 | 업체 상세` 구조라면, 바둑판조회는 업체를 가로 열로 배치하고 항목을 세로 행으로 배치한다.

## 진입 위치

- 메뉴명: `바둑판조회`
- 라우트: `#/company-grid`
- 주요 파일:
  - `src/view/features/company-grid/pages/CompanyGridPage.jsx`
  - `src/styles.css`
  - `src/App.jsx`
  - `src/components/Sidebar.jsx`

## 기본 구조

- 한 블록에 업체 `12개`씩 표시한다.
- 각 업체는 한 열로 표시된다.
- 항목은 세로 행으로 반복된다.

표시 항목:

- 회사명
- 대표자
- 사업자번호
- 지역
- 시공능력
- 3년간 실적액
- 5년간 실적액
- 부채비율
- 유동비율
- 영업기간
- 신용등급
- 여성기업
- 중소기업
- 일자리창출평가
- 시공품질평가
- 비고

## 데이터 상태 색상

기존 업체조회에서 쓰던 최신자료 구분을 뱃지 대신 셀 배경색으로 표시한다.

- 최신자료: 연녹색
- 1년 경과: 연파랑
- 1년 이상 또는 상태 없음: 흰색

## 전체 공종 구분

공종을 `전체`로 조회하면 전기/통신/소방 업체가 같이 나오므로 회사명 셀 배경색으로 공종을 구분한다.

- 전기: 연노랑
- 통신: 연파랑
- 소방: 연빨강

단일 공종 조회에서는 회사명 행의 기존 회색 배경을 유지한다.

## 검색 및 필터

상단 툴바에 주요 조작을 모았다.

- 공종 선택
- 검색/필터 열기
- 초기화
- 전체복사
- 검색
- 지역 포함/제외 탭
- 결과 요약

검색/필터 패널에는 지역 조건을 넣지 않는다. 지역 조건은 상단 지역 탭에서만 관리한다.

검색/필터 항목:

- 업체명
- 사업자번호
- 담당자 포함
- 담당자 제외
- 시공능력 최소/최대
- 3년 실적 최소/최대
- 5년 실적 최소/최대
- 최소 신용등급

동작:

- 검색/필터 버튼을 다시 누르면 닫힌다.
- `Esc`를 누르면 닫힌다.
- 검색/필터 안에서 검색해도 패널은 닫히지 않는다.
- 메인 화면 또는 필터 입력 중 `Enter`를 누르면 검색한다.

## 지역 조건

지역 조건은 검색/필터 내부가 아니라 상단 툴바 안에서 관리한다.

### 포함

- `전체` 또는 복수 지역 선택 가능
- `전체`은 포함 지역이 비어 있는 상태이다.
- 예: 부산, 울산 선택 시 부산+울산만 검색한다.
- 선택한 지역을 다시 누르면 해제된다.

### 제외

- 복수 지역 선택 가능
- 포함 결과에서 제외 지역을 뺀다.
- 예: 포함 전체, 제외 제주 → 제주 제외 전체
- 예: 포함 부산+울산, 제외 울산 → 부산만 표시

## 검색 결과 표시와 더 보기

전체 공종 검색 시 결과가 많으면 렌더링 셀이 많아져 렉이 걸릴 수 있다.

이를 줄이기 위해 검색 결과는 전체를 받아오되 화면에는 처음 `240건`만 렌더링한다.

- 하단 `더 보기` 버튼을 누르면 `240건`씩 추가 표시한다.
- 결과 요약에는 전체 결과 수와 현재 표시 수를 보여준다.
- 더 보기로 늘린 표시 개수는 직전 화면 기억에 저장된다.

## 직전 화면 기억

바둑판조회는 직전 화면 상태를 저장하고 복원한다.

저장 항목:

- 공종
- 지역 포함
- 지역 제외
- 지역 목록
- 검색/필터 입력값
- 검색/필터 열림 여부
- 검색 결과
- 표시 개수
- 선택 업체
- 총 결과 수
- 검색 여부

저장 키:

- `company-grid-state`

기존 지역포함/지역제외 필터 저장값이 남아 있어도 새 상단 탭 상태로 읽히도록 호환 처리했다.

## 업체 선택 및 전체복사

업체 열 아무 셀이나 클릭하면 해당 업체 열이 선택된다.

- 선택된 업체 열은 주황색 테두리/배경으로 표시된다.
- 같은 업체를 다시 클릭하면 선택이 해제된다.
- 선택 업체가 있을 때만 `전체복사` 버튼이 활성화된다.

전체복사는 기존 업체조회와 같은 순서로 엑셀 붙여넣기용 1열 데이터를 복사한다.

공종이 `전체`일 때 같은 사업자번호가 전기/통신/소방에 모두 있을 수 있으므로, 선택 키에는 공종을 포함한다.

예:

- `eung|biz:사업자번호`
- `tongsin|biz:사업자번호`
- `sobang|biz:사업자번호`

그래서 같은 업체가 여러 공종에 있어도 클릭한 공종의 열만 선택된다.

## 낙찰이력 표시

기존 업체조회처럼 LH 또는 도로공사 낙찰이력이 있는 업체를 표시한다.

- 낙찰이력이 있는 업체명은 빨간색 굵은 글씨로 표시한다.
- 회사명 옆 빨간 느낌표 아이콘을 표시한다.
- 아이콘에 마우스를 올리면 발주처와 계약기간을 툴팁으로 보여준다.

## 경고 표시

기존 업체조회와 같은 기준으로 부채비율, 유동비율, 영업기간을 빨간색 강조한다.

기준 파일:

- 평균값: `src/shared/industryAverages.json`
- 계수: `src/ratios.js`

현재 공식:

- 부채비율 경고 기준 = 업종 평균 부채비율 × `DEBT_RATIO_WARN_FACTOR`
- 유동비율 경고 기준 = 업종 평균 유동비율 × `CURRENT_RATIO_WARN_FACTOR`
- 영업기간은 3년 미만이면 빨간색

현재 계수:

- `DEBT_RATIO_WARN_FACTOR = 0.5`
- `CURRENT_RATIO_WARN_FACTOR = 1.5`

## 데이터 갱신 이벤트

기존 업체조회처럼 `searchClient.onDataUpdated(...)` 이벤트를 구독한다.

데이터가 갱신되면:

- 지역 목록을 다시 불러온다.
- 이미 검색한 상태라면 현재 조건으로 자동 재검색한다.
- 선택 업체가 새 결과에 있으면 유지한다.
- 선택 업체가 새 결과에 없으면 선택 해제한다.
- 더 보기로 늘려둔 표시 개수는 유지한다.

## 주의사항

- 바둑판조회는 기존 업체조회 기능을 대체하지 않는다.
- 기존 업체조회 로직은 건드리지 않고 별도 화면으로 구현했다.
- 전체 공종 검색은 결과가 많을 수 있으므로 더 보기 방식으로 렌더링 부하를 줄인다.
- 검색 결과는 재조회 시 최신 데이터 기준으로 교체된다.
- 직전 화면 기억 때문에 화면 진입 직후에는 저장된 예전 결과가 보일 수 있지만, 검색을 다시 누르면 최신 데이터로 조회된다.
