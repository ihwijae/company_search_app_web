# 한국가스공사 협정보드 구현 정리

## 작업 개요

협정보드 발주처에 `한국가스공사`를 추가했다.

한국가스공사는 입찰/협정 기준은 조달청과 동일하게 사용하되,
협정문자와 아이건설넷 메모에서 사업자번호 표시 방식만 다르게 처리한다.

지원 구간:

- 한국가스공사 50억 미만
- 한국가스공사 50억~100억

---

## 기준 적용 방식

한국가스공사는 조달청 기준을 그대로 따른다.

적용 대상:

- 협정보드 계산 기준
- 후보 점수 계산
- 지역사 찾기
- 신인도 기준
- 실적 기준
- 단독 가능 여부 판단 기준

구현상 한국가스공사 발주처는 별도 `ownerId`를 가지지만,
점수 계산과 후보 평가에서는 조달청 기준으로 매핑해서 처리한다.

---

## 협정문자 생성 규칙

한국가스공사는 협정문자 생성 시 조달청과 다르게 처리한다.

한국가스공사는 구성사가 협정서를 올리는 흐름이므로,
문자에 대표사 사업자번호를 같이 표시해야 한다.

출력 규칙:

- 대표사: 사업자번호 표시
- 구성사: 사업자번호 표시하지 않음

예:

```text
[한국가스공사]
123 테스트 공고

대표사 51% [123-45-67890]
구성사 49%

협정 부탁드립니다.
```

주의:

- LH처럼 대표사 사업자번호를 표시한다.
- LH와 동일하게 구성사 사업자번호는 표시하지 않는다.
- 조달청 기본 문자 포맷처럼 구성사 사업자번호가 붙으면 안 된다.

---

## 아이건설넷 메모 규칙

아이건설넷 메모도 협정문자와 동일한 사업자번호 표시 규칙을 사용한다.

출력 규칙:

- 대표사: 사업자번호 표시
- 구성사: 사업자번호 표시하지 않음

예:

```text
아람이엔테크 51% [111-11-11111]
구성사 49%
```

구현상 `KGAS`, `한국가스공사`, `가스공사` 모두 한국가스공사 발주처로 인식하도록 처리했다.
따라서 저장 데이터나 화면 상태에서 발주처 값이 표시명으로 들어와도 동일한 메모 규칙이 적용되어야 한다.

---

## 엑셀 내보내기 상태

### 50억 미만

한국가스공사 50억 미만은 조달청 50억 미만 엑셀 템플릿과 설정을 그대로 재사용한다.

현재 상태:

- 계산 가능
- 협정보드 사용 가능
- 엑셀 내보내기 가능
- 조달청 50억 미만 템플릿 사용

### 50억~100억

한국가스공사 50억~100억은 조달청 50억~100억 기준을 따른다.

다만 조달청 50억~100억 자체가 아직 웹 엑셀 템플릿이 연결되지 않은 상태이므로,
한국가스공사도 같은 상태로 둔다.

현재 상태:

- 계산 가능
- 협정보드 사용 가능
- 엑셀 내보내기 미구현
- 조달청 50억~100억 템플릿이 구현되면 한국가스공사도 함께 연결 검토 필요

---

## 구현 지점 요약

주요 구현 방향:

- 발주처 메뉴와 라우트에 한국가스공사 추가
- 한국가스공사는 조달청 기준을 쓰도록 기준 발주처 매핑 추가
- 협정문자 생성 시 한국가스공사는 대표사 사업자번호만 표시
- 아이건설넷 메모 생성 시 한국가스공사는 대표사 사업자번호만 표시
- 한국가스공사 50억 미만은 조달청 50억 미만 엑셀 템플릿 재사용
- 한국가스공사 50억~100억은 계산만 열고 엑셀 내보내기는 미구현 상태 유지

관련 파일:

- `src/shared/navigation.js`
- `src/shared/agreements/ownerCriteria.js`
- `src/shared/agreements/generator.js`
- `src/shared/agreements/calculations/inconMemo.js`
- `src/shared/agreements/templateConfigs.web.js`

---

## 검증 내용

확인한 내용:

- 한국가스공사 메뉴/라우트 추가
- 한국가스공사 기준이 조달청 기준으로 매핑되는지 확인
- 협정문자 샘플에서 대표사 사업자번호만 표시되는지 확인
- 아이건설넷 메모 샘플에서 대표사 사업자번호만 표시되는지 확인
- `npm run build` 통과

빌드 참고:

- `db` 디렉터리가 없으면 `build-static-datasets`는 skip 된다.
- Vite 청크 크기 경고와 `sql.js` 브라우저 외부화 경고는 기존 성격의 경고다.
